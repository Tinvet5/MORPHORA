# MORPHORA V4.1 — Wide Logo Hero

This update changes only the species-library landing hero. The official full logo is displayed across the page rather than inside a square card.

## Install

Copy the contents of this folder into the GitHub Pages publishing root and keep the existing `CNAME` file. Replace `index.html`, `style.css`, `script.js`, and `navigation.js` together so the `4.1.0` cache versions remain synchronized.

## Unchanged

The species catalog, multi-collection routing, OpenSeadragon viewer, labels, annotations, information panel, JSON architecture, and dark/light modes are preserved.
