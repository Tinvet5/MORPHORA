# MORPHORA V5.0.3 — Profile & Preferences Smoke Test

1. Sign in to a test account and open the account panel.
2. Confirm display name, email, member-since date, and sign-in method render correctly.
3. Change the display name, save, close/reopen the panel, and refresh the page. Confirm it persists and the header initials update.
4. Set language to English, save, refresh, and confirm the interface remains English.
5. Set language to Spanish, save, refresh, and confirm the interface remains Spanish.
6. Set theme to Dark, Light, and System; save each and verify the interface changes immediately.
7. On a second browser/device, sign into the same test account and confirm language/theme are restored from the account.
8. Use the normal header language menu and theme toggle while signed in; reopen the account panel and confirm the cloud preference state matches.
9. Sign out and confirm the atlas remains usable and existing local study data remains present.
10. Verify notes, drawings, and study progress are not visible on a second browser/device yet (expected until V5.0.4).
