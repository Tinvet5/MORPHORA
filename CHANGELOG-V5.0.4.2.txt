MORPHORA V5.0.4.2 — Notes & Bookmarks Cloud Sync

- Added local-first cross-device synchronization for personal notes.
- Added structure bookmarks/favorites with a dedicated My bookmarks drawer.
- Added automatic, idempotent adoption of existing local notes into signed-in accounts.
- Added cloud pull/merge for newer note and bookmark copies.
- Added tombstone-aware deletion propagation to prevent deleted data reappearing.
- Added revision-aware conflict detection for concurrent device edits.
- Added per-account personal sync metadata and queue isolation.
- Added local/syncing/synced/offline/conflict status for personal data.
- Added bookmark backup/export support.
- Added V5.0.4.2 runtime, security, and production release gates.
- No new Supabase migration required beyond V5.0.4.1 cloud sync foundation.
- Drawings and Study/Quiz progress intentionally remain local-only.
