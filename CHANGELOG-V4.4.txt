ADDED

- #/studio redirect from the main application.
- Species, system, collection, and view selectors generated from MORPHORA JSON.

- Undo and redo history.
- LocalStorage draft saving and restoration.
- Unsaved-change protection.
- JSON validation, import, clipboard copy, and file export.
- Keyboard shortcuts.
- Responsive Studio layout.

- Main view validator preserves additional editorial metadata.

- VIEW-TEMPLATE.json expanded with the new optional fields.

SECURITY NOTE
