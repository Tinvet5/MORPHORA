# Generated Histology WSI derivatives

This directory is the default local output for DZI pyramids produced by `tools/histology_wsi/convert_to_dzi.py` and `pilot_slide.py`.

Generated slide pyramids can contain many thousands of tile files and must **not** be committed to the MORPHORA Git repository. Keep the original MDSX packages private as archival masters, and publish web derivatives to object storage/CDN.
