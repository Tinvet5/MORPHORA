A focused visual patch to V4.9.7.1. This release does not alter anatomy geometry, schemas, Deep Zoom assets, Study/Quiz IDs, or user-data formats.

- Repairs the malformed footer CSS block from V4.9.7.1.
- Keeps the footer brand mark intentionally small and contained.

- Preserves each social/contact destination as its own accessible link.

- Improves footer wrapping at tablet and mobile sizes.

## Compatibility
No content migration is required. Existing bilingual anatomy content, notes, drawings, learning progress, Studio drafts, question banks, and Deep Zoom assets remain compatible.
