# MORPHORA Histology POC v0.2.1

Visual-polish update built on Histology POC v0.2.

## What changed

- Cleaner H&E-inspired Histology hero artwork with more negative space.
- Histology-specific pink MORPHORA wordmark and icon derived from the supplied pink logo.
- Pink Histology branding is used in compact UI placements rather than as an oversized hero logo.
- Histology menu, whole-slide viewer and main MORPHORA Histology entry now share the same pink module identity.
- PMA.start/OpenSeadragon behavior is unchanged.

## Local test

1. Keep PMA.start running.
2. Serve `index.html` with Live Server.
3. Open **Histology** from MORPHORA Home.
4. Open the equine abscessed lymph node H&E slide.
5. Authorize PMA.start if requested and connect the slide.
6. Confirm 5×, 10×, 20× and 40× navigation still works.
